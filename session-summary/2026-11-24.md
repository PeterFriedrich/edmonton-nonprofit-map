## 3. Technical Learnings
- **CRA's open.canada.ca download URLs redirect** to Azure blob storage, so curl needs `-L`; without it you get a 710-byte "Redirecting" HTML page. The project downloader already follows redirects.
- **Qualified donees file:**
  - `Total Gifts` includes gifts in kind: on lines with both, it is at least the in-kind value in 25,657 of 25,768 lines across the file.
  - About 9% of all lines have a blank or malformed `Donee BN`.
  - 84 lines filed by map charities carry a well-formed BN that isn't the named map charity's; they look like typos and are deliberately not linked.
- `tools/todo_archive.py` can eat the blank line before the next `###` heading in `TODO.md`. Check the diff after running it.
- `/code-review` runs as a background fork; `/security-review` asks for a sub-task. Both took about 1 to 1.5 minutes here.
- A wait like `until gh pr checks <b> --watch ... | grep -q -E 'pass|fail'` returns as soon as the check registers as pending; run `gh pr checks <n> --watch` again to get the result.
- GitHub's licence detection lagged a few minutes after the PR #17 merge.
- The headless verify script was `scratchpad/verify.js` (session scratch, auto-deleted). It uses the Playwright in `~/edmonton-civic-map/node_modules` with `executablePath` set to the 1228 headless shell (see the 2026-11-20 handoff).
- Disk: 79% used, 7.6 GB free. `data/raw/` is now about 120 MB.
