## 3. Technical Learnings
- **CRA CSVs and the datastore API disagree:** 84,057 against 83,761 BNs in ident. That is why the download guard checks the file rather than a server count. `docs/DATA_ISSUES.md` records this as NOT SENT, and telling CRA is the owner's call (TODO housekeeping).
- **CRA `City` is free text.** Places appear in several spellings (`ST ALBERT`, `ST-ALBERT`, `FT-SASKATCHWN`) and as county or hamlet names (`STURGEON COUNTY`, `NISKU`, `ACHESON`). The look-alike test matches on shared 5+ letter words, ignoring `COUNTY` and `RURAL`. It only runs where `data/raw/` exists, so it skips in CI.
- **Alberta listing:** 70,383 data rows; row 1 is blank, the header is on row 2, and the `' City'` header has a leading space.
- **Box quirks:** Wikipedia's API returned 429 to urllib (WebFetch worked). `certifi` is in the project `.venv`, not in python3.12.
- **Public-repo rule:** never name the prospective partner org or outreach plans in repo text. Use "volunteer groups".
- `docs/BRIEF.md` has not been generated yet, so there is no Project-sync check. PRs #2 and #3 still asked for Sync of `data/DATA.md` and `docs/SPEC_map.md`.
