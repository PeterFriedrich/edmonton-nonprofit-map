## 3. Technical Learnings
- **The handoff of 2026-11-18 was wrong about `certifi`.** It is not installed in `.venv`, which is a symlink to `/usr/bin/python3.12` with no site packages. The CKAN fetch through `src/ckan_download.py` works with the system certificates. Use `fetch_package()` to list a dataset's resources.
- **open.canada.ca resource URLs 302 to Azure blob storage**, so use `curl -L`. Without it you save a 700-byte HTML redirect named `.pdf`.
- **Reading PDFs on this box:** no `pdftoppm` or `pdftotext`, so the Read tool can't open PDFs. Install `pypdf` with `python3.12 -m pip install --target <scratch>/lib pypdf` and extract text.
- **Parsing the Codes Lists PDF:** for these two-column tables the plain extraction beats `extraction_mode="layout"`, which cut 52 labels. In the plain text a cell ends at a line ending in two spaces. One label (`0150-0005`) ended early and was completed by hand.
- **CRA data dictionary v2.0:** most amounts are "Empty for exempt charities", and "exempt" is never defined. Schedule 3 exists exactly when line 3400 = Y (1,284 Y, of which 1,275 have a row; no row without Y).
- **Blank is not zero in Schedule 3:** line 300 is blank 159 times and 0 42 times.
- **Total compensation disagrees between files:** lines 390 and 4880 differ for 118 of 1,124 charities, so neither is used.
- **The `general_info.csv` header `5030  ` has trailing spaces;** `read_csv` strips keys.
- **Flag matching:** `"category_not_decoded"` is a substring of `"sub_category_not_decoded"`. Always test flags with `.split(";")`, never with `in`.
- **`tools/todo_archive.py` copies a date out of the item's text into the `## Done` stub.** The director item got "2026-11-14" from its own wording. Check the stubs after running it.
- **GitHub's merge button defaults to the method the owner last used:** #4–#7 were squash merges, #1–#3 merge commits. For a squash merge, confirm landing by comparing trees (`git diff --stat origin/<branch> origin/master`); `merge-base --is-ancestor` on the branch tip fails.
- **Scratch for this session:** `/tmp/claude-1000/-home-opc-edmonton-nonprofit-map/e9391514-253e-496d-84fe-8f0e754bf7db/scratchpad/`. It holds `cra_pdfs/` (`dict.pdf`, `codes.pdf`), the text extractions and the parse scripts. Nothing there is needed again; it is auto-deleted after 7 days.
