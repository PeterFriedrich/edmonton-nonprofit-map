## 3. Technical Learnings
- **The 2026-11-19 handoff was wrong about `.venv`.** It is a real uv venv (`uv 0.13.1`, `include-system-site-packages = false`) with its own site-packages. Install with `uv pip install --python .venv/bin/python …`. It is now 548 MB.
- **Fastembed's default model cache is under `/tmp`.** The code points it at `data/processed/fastembed_cache/` (`--model-cache`). The download needs network access to huggingface.co.
- **Embedding takes longer than its size suggests.** Fastembed pads each batch to its longest text, and descriptions run to 2,497 characters, about 500 tokens. 6 minutes cold, using 23 CPU-minutes.
- **UMAP with `random_state` warns that it disables parallelism.** That is expected; it is what makes the output deterministic. About 60 seconds, including numba compilation.
- **numpy sorts of 16 elements or fewer use insertion sort**, which is stable, so a tie test on a small array can't tell `stable` from `quicksort`. Use more than 16 rows.
- **`/security-review` needs `origin/HEAD`:** the first launch failed on `git diff origin/HEAD...`. Fixed with `git remote set-head origin master`.
- **Programs data on our 2,430:** each charity has at most one `OP` row at its period, and none has an `OP` row only for another period (`data/DATA.md`).
- **`check_requirements.py`** maps `umap` to `umap-learn` through the `# import: umap` note on the pin.
- `numpy.load` defaults to `allow_pickle=False` in 2.5.5, checked in `.venv`.
- **Scratch:** `/tmp/claude-1000/-home-opc-edmonton-nonprofit-map/80e5513b-a45f-4b12-ae18-5d4166c22815/scratchpad/`. It holds the mutation backups, `civenv/` (a CI-like venv) and `models/` (a test model copy). None of it is needed again; it is auto-deleted after 7 days.

- **Headless browser on this box:** `/home/opc/.cache/ms-playwright/chromium_headless_shell-1228/chrome-linux/headless_shell`. Node Playwright lives only in `/home/opc/edmonton-civic-map/node_modules`; use it with `NODE_PATH=...` and `executablePath` set to the 1228 shell, because that Playwright wants a missing 1243 build. My verify script was `scratchpad/verify.js` (session scratch, will be deleted).
- **Port 8765 is taken** by `edmonton-open-data-landscape-mcp`'s MCP server. Serve `_site/` on a free port (`socket.bind(('127.0.0.1', 0))`).
- **`<details>` ignores `display: contents` in Chromium**; it broke the desktop filter row. It is now a flex item and the summary is hidden above 760 px.
- **`Element.append(null)` writes the text "null".** Use the `add()` helper in `app.js`, which drops nulls.
- **UMAP's neighbour graph (`graph_`) is one connected component**, yet the 41 near-identical texts sit far off. That's why the layout fix was scaling, not moving the island.
- **The dataviz palette caps a scatter at three categorical colours** (all-pairs checks); `scripts/validate_palette.js --pairs all`.
- **`pypdf` is not in `.venv`.** I read the codes PDF from a throwaway venv in scratch. `config/cra_codes.json` has the labels but not the four §2.2 heads; those live only in `app.js` `HEADS` and SPEC §4.
